## Operating guides

The updated milling guides are being planned. The older PDFs predate the current website and its cutter/settings choices; they are not the current operating instructions for this application.

The intended set is:

- **KiCad to finished PCB:** a visual website guide and matching printable PDF, following the Ampoteket application.
- **Gerber2PNG + Mods backup workflow:** separate instructions for preparing files when using the original tools.
- **At the machine:** a short printed run-order and setup reference, with a QR code leading to the current guide page.

The [plan](DOCUMENTATION_PLAN.md) describes their contents and publication order. Download links will be added when those guides are ready.

## What belongs here

These documents describe the current website and how to look after it. Change history belongs in the repository's commit history. Milling instructions belong in the user guide. Original equipment manuals remain references. This keeps a new student from having to work through old conversations and development notes to find the current procedure.
