How the transfer works

Both computers need internet access and an up-to-date browser. PeerJS Cloud helps the browsers connect; the file is sent between them and is not stored on a server.

If a university network or the Windows VM blocks the connection, try a different network. The milling app’s normal ZIP download remains available. This page receives files; it does not start the mill.
