About this application

Gerber2PNG by FabLab Kerala and pcb-stackup convert the board; Mods generates the toolpaths and RML files. Original source notices and pinned versions are retained locally. No machine is connected. Cutting defaults have not been physically validated for the lab tools.

Send to machine

On the computer you use for VPanel, open the receiving page. Keep both pages open during the transfer.

The other computer must accept the job before it is sent. PeerJS Cloud helps the browsers connect; jobs are not stored there. Sending a file does not start the mill.
